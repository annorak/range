## Session context

The timeline carries model (4.3) + host (4.4) events. This step adds the **network
dimension**: inter-host flows, DNS queries, HTTP metadata, and on-demand PCAP
slices, captured at the network fabric (2.3) and normalized to `NetworkEvent`s
(4.1) in the `TraceStore`. Flows correlate to hosts via the IP map from 2.3.

## Implementation details

- **Capture point**: a **tap container** attached at the router bridges (2.3), or
  `tcpdump`/eBPF flow tracing on the router. Capture per-run; **rotate PCAPs**
  (size/time bounded — never unbounded).
- **Events** (4.1 `NetworkEvent`): `flow` (src/dst host, proto, ports, bytes),
  `dns` (query), `http` (method/url/status, metadata only), and `pcap_ref`
  (pointer to a raw PCAP slice).
- **Keep the stream light**: store flow/DNS/HTTP **summaries inline**; store raw
  **PCAP as referenced blobs** (`pcap_ref` → blob path in the 4.2 store — block
  volume by default, object storage if enabled). Slice PCAPs on demand around a
  window rather than retaining everything.
- **Correlation**: resolve IPs → `host_id` via the 2.3 IP map; tag with the run's
  `CorrelationIds`; align to `step_seq` by wall-clock (like host events).

## Infrastructure (Terraform)

- **No new OCI resource for the captor** — the tap is a **Docker container** on the
  range network (2.3), running on the 0.3 host; events persist via the 4.2
  `TraceStore`.
- **PCAP blobs** reuse the 4.2 blob store: the **block volume** by default, or the
  optional **OCI Object Storage** bucket when `enable_object_storage` is set.
  Because PCAPs are bulky, this is the most likely first trigger to flip object
  storage on (and to set a retention/lifecycle policy — backlog **B-36**). Keep
  rotation bounded so the block volume can't fill.
- `@pytest.mark.docker` capture tests run on the host.

  on the same timeline as model + host.

## Engineering standards

All of `_SHARED_STANDARDS.md`. **PCAP volume is bounded/rotated — never unbounded
capture.** Summaries inline, raw PCAP as referenced blobs. Reuse the 4.2 blob
store (don't invent a second one). Comment the *why* on rotation bounds and the
inline-summary/blob-ref split.
