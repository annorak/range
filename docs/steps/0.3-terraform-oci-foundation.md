# Step 0.3 — Infrastructure foundation: Terraform + OCI host  `[MVP]`

> **Claude Code session prompt.** Self-contained. Read
> `docs/steps/_SHARED_STANDARDS.md` first (especially the **Infrastructure as
> Code** section).

## Session context

Range's execution substrate for v1 is a **single OCI x86 VM** running Docker +
gVisor (`runsc`); the control plane co-locates there. This step writes the
**Terraform** that stands that host up reproducibly, so that from Step 2.2 onward
the `@pytest.mark.docker` integration tests have a real, version-controlled host
to run against. This is the IaC foundation (design decision **D9**) every later
infra need extends — *surgically*, one resource at a time.

No Range application code is written here. The deliverable is `deploy/terraform/`
+ the bootstrapped runtime + the CI/Make plumbing.

## Goal

`make tf-apply` stands up an Ubuntu 24.04 x86 host with Docker + `runsc` + uv;
`docker run --runtime=runsc --rm hello-world` works on it; `terraform destroy`
removes everything; `terraform fmt -check` + `validate` are green in CI.

## Scope (build this)

- `deploy/terraform/` root module (flat — no child modules yet; YAGNI):
  `versions.tf`, `variables.tf`, `network.tf`, `compute.tf`, `outputs.tf`,
  `terraform.tfvars.example`.
- `deploy/terraform/cloud-init/bootstrap.yaml` — installs Docker CE, gVisor
  `runsc` (+ daemon.json runtime), Python 3.12 + uv; optional Tailscale.
- A CI **`infra`** job: `terraform fmt -check` + `terraform validate` (+ optional
  `tflint`). **Never `apply` in CI.**
- `Makefile` `tf-*` targets (from the shared standards).
- `docs/adr/0003-iac-terraform-oci.md` — record the IaC decision.
- `.gitignore` additions: `*.tfvars` (keep `*.tfvars.example`), `.terraform/`,
  `*.tfstate*`, `*.tfplan`.
- `deploy/README.md` — bootstrap + smoke-check + stop/start + teardown runbook.

## Out of scope

- Any Range *application* resource beyond the host: Postgres, object storage, and
  OCIR are added by the steps that need them (Epic 4, 2.5). **Do not** pre-create
  them.
- Remote TF state (OCI Object Storage backend) → backlog **B-32**.
- A self-hosted CI runner on the host → backlog **B-33**.
- Multi-host / autoscaling → Epic 7 + cloud backend (B-29).

## Deps introduced this step

Terraform CLI (operator tool, not a Python dep) and the `hashicorp/oci` provider
(pinned in `versions.tf`). No Python package changes.

## Implementation details

### `versions.tf`
```hcl
terraform {
  required_version = ">= 1.6"
  required_providers {
    oci = { source = "oracle/oci", version = "~> 6.0" }   # the official OCI provider
  }
}
provider "oci" {
  # Auth from the operator's ~/.oci/config (API-key). Region from var.
  region = var.region
}
```

### `variables.tf` (sane defaults; secrets via tfvars)
- `region` (string), `compartment_ocid` (string), `tenancy_ocid` (string).
- `instance_shape` = `"VM.Standard.E4.Flex"` (x86 AMD flex).
- `instance_ocpus` = `4`, `instance_memory_gb` = `24`.
- `ssh_public_key` (string) — operator's key.
- `allowed_ssh_cidr` (string) — operator IP/CIDR (default `"0.0.0.0/0"` but the
  example tfvars tells the operator to lock it to their IP).
- `os_image_ocid` (string, optional) — if empty, look up the latest Canonical
  Ubuntu 24.04 x86_64 image via a data source.
- `block_volume_gb` = `100`.
- `env` = `"dev"`.
- A local `common_tags = { project = "range", env = var.env, managed_by = "terraform" }`.

### `network.tf`
- `oci_core_vcn` (`10.0.0.0/16`).
- `oci_core_internet_gateway` + `oci_core_route_table` (default route to IGW).
- `oci_core_subnet` (`10.0.1.0/24`, public, associated with the route table).
- `oci_core_network_security_group` + rules (prefer NSG over security lists):
  - **Ingress:** TCP 22 from `var.allowed_ssh_cidr` only. (No other ingress —
    use Tailscale/SSH-tunnel for the API/UI later; don't open it.)
  - **Egress:** allow TCP 443 (model APIs, registries) and UDP/TCP 53 (DNS) to
    `0.0.0.0/0`; deny the rest. *(The host needs outbound; the **range
    containers'** egress is denied separately, in-Docker, by 2.3.)*

### `compute.tf`
- (data) `oci_core_images` filtered to Canonical Ubuntu 24.04 x86_64 when
  `os_image_ocid` is empty.
- `oci_core_instance`:
  - `shape = var.instance_shape`, `shape_config { ocpus, memory_in_gbs }`.
  - `source_details` → the Ubuntu image; `create_vnic_details` → the subnet + NSG,
    `assign_public_ip = true`.
  - `metadata = { ssh_authorized_keys = var.ssh_public_key, user_data =
    base64encode(file("${path.module}/cloud-init/bootstrap.yaml")) }`.
  - `freeform_tags = local.common_tags`.
- `oci_core_volume` (`var.block_volume_gb`) + `oci_core_volume_attachment`
  (paravirtualized) for `/var/lib/docker` or `/data` (trace/state survives
  instance recreation). Tag it.

### `outputs.tf`
- `instance_public_ip`, `instance_id`, `ssh_command` (`"ssh ubuntu@<ip>"`). Mark
  nothing secret here; no keys in outputs.

### `cloud-init/bootstrap.yaml`
A `#cloud-config` that, on first boot:
1. Installs **Docker CE** from the official apt repo; enables the service; adds
   `ubuntu` to the `docker` group.
2. Installs **gVisor `runsc`**: add the gVisor apt repo
   (`https://storage.googleapis.com/gvisor/releases release main`), install
   `runsc`, then write `/etc/docker/daemon.json`:
   ```json
   { "runtimes": { "runsc": { "path": "/usr/bin/runsc" } } }
   ```
   and restart Docker. *(2.4 may refine runsc flags, e.g. `--net-raw`; leave that
   to 2.4.)*
3. Installs **Python 3.12** + **uv** (`curl -LsSf https://astral.sh/uv/install.sh`).
4. (Optional) Installs **Tailscale** if a `var.tailscale_auth_key` is provided —
   keep this behind a default-off variable; don't require it.
5. Mounts the attached block volume at `/data` (format if new), and points Docker
   data-root there if desired (document the choice).

Keep the cloud-init idempotent and minimal — it is config, not a kitchen sink.

### CI `infra` job (`.github/workflows/ci.yml`)
Add a job using `hashicorp/setup-terraform`:
- `terraform -chdir=deploy/terraform fmt -check`
- `terraform -chdir=deploy/terraform init -backend=false`
- `terraform -chdir=deploy/terraform validate`
- (optional) `tflint`
No OCI creds in CI; **no `apply`/`plan` against real OCI** (validate only).

## Contracts produced

- The `deploy/terraform/` module + outputs (`instance_public_ip`, `ssh_command`).
- The bootstrapped runtime (Docker + `runsc` + uv) that **2.2+ integration tests
  target**.
- The `tf-*` + `host-smoke` make targets and the CI `infra` gate.
- The **per-step infra workflow**: later steps add only their resource, reviewed
  by `terraform plan`, applied by the operator, proven by a smoke check.

## Testing

**CI (always):**
- `terraform fmt -check` clean, `terraform validate` passes (with
  `init -backend=false`). Optional `tflint` clean.

**Operator post-apply smoke (needs real OCI creds — documented in `deploy/README.md`):**
- `make tf-apply` succeeds.
- `make host-smoke` shows the `runsc` runtime present, `hello-world` runs under
  `--runtime=runsc`, and `uv --version` prints.
- `make tf-destroy` removes all resources (verify in the OCI console / a second
  `plan` shows no drift before destroy).

> This step has no Python unit tests — it produces infra, not library code. Its
> gate is `validate` in CI + the operator smoke check. That is the "test as we go"
> contract: the host is proven before 2.2's code depends on it.

## Engineering standards

All of `_SHARED_STANDARDS.md`, IaC section especially: pinned provider, no secrets
