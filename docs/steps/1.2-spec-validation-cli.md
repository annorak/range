# Step 1.2 — Spec validation, linting & `range validate`  `[MVP]`

> **Claude Code session prompt.** Self-contained. Read

## Session context

The scenario schema + loader exist (1.1). A spec can be *parsed* but not yet
*checked for sense*. This step adds **semantic validation + linting** and the
first real CLI subcommand, `range validate`, so broken ranges are caught **before
any compute is spent**. All checks are static — no provisioning, no live probes.

`spec` stays pure. Use `SpecError` only for internal misuse; validation results
are **returned as data** (`Diagnostic`s), never raised.

## Goal

`range validate <file>` passes the reference range with zero errors and fails a
curated set of broken specs, each tripping the **correct stable diagnostic code**.

## Scope (build this)

- `spec/diagnostics.py` — the `Diagnostic` model + helpers (reused by reports
  later).
- `spec/validate.py` — `validate(scenario, *, strict=False) -> list[Diagnostic]`
  with the checks below.
- `cli/main.py` — add the `validate` subcommand (the app stub exists from 0.1).
- `docs/diagnostics.md` — the stable code table (these codes are an API).

## Out of scope

- Provisioning and any runtime reachability — **static checks only** (reachability

- Milestone **DAG** validation and fragments → Step 1.3 (this step validates

## Implementation details

### `spec/diagnostics.py`
```python
Severity = Literal["error", "warning"]

class Diagnostic(BaseModel):
    model_config = ConfigDict(frozen=True)
    severity: Severity
    code: str            # stable, dotted — an API (see docs/diagnostics.md)
    loc: str             # logical pointer, e.g. "hosts[2].subnet"
    message: str
    hint: str | None = None

def has_errors(diags: Iterable[Diagnostic]) -> bool: ...
def format_report(diags: Sequence[Diagnostic]) -> str:
    """Human-readable, grouped by severity. Plain text (no color dependency)."""
```
> `loc` is a **logical path string**, not a YAML line number. Line numbers are for
> parse/schema errors (1.1); semantic checks operate on the model tree, so a
> pointer like `hosts[2].subnet` is the right, dependency-free locator.

### `spec/validate.py`
`validate(scenario, *, strict=False) -> list[Diagnostic]` runs all checks and
returns the collected diagnostics. `--strict` promotes warnings to errors (do the
promotion in the CLI or via a flag passed through — keep `validate` returning the
honest severities and let the caller decide, or accept `strict` and promote;
pick one and document it). Keep each check a **small named function** returning
its diagnostics; `validate` concatenates them (DRY, skimmable).

**Errors (must trip the exact code):**

| code | check |
|------|-------|
| `spec.ref.subnet_missing` | a `host.subnet` names no subnet in `network.subnets` |
| `spec.ref.identity_location_missing` | an `identity.locations` entry names no host |
| `spec.ref.flag_id_duplicate` | the same `flag_id` appears on more than one file |
| `spec.ref.milestone_flag_unresolved` | a `milestone.flags` entry names no `flag_id` |
| `spec.net.cidr_invalid` | a subnet `cidr` is not a valid network |
| `spec.net.cidr_overlap` | two subnets overlap |
| `spec.net.host_overflow` | more hosts placed in a subnet than its CIDR can address |
| `spec.net.router_cardinality` | a multi-subnet network lacks exactly one `router` (or an explicit gateway) |
| `spec.image.unpinned` | a host `image` is not digest-pinned and violates the tag policy |
| `spec.resources.exceed_caps` | summed `cpu`/`memory_mb` exceed configured caps |
| `spec.egress.malformed` | an egress-allowlist entry is not a valid CIDR/host |

**Warnings (lint):**

| code | check |
|------|-------|
| `spec.lint.host_no_services` | a non-router host exposes no services |
| `spec.lint.subnet_unreachable` | a subnet is not reachable from the entry subnet |
| `spec.lint.flag_uncovered` | a flag is referenced by no milestone |

Implementation notes:
- CIDR math via `ipaddress` (`ip_network`, `.overlaps`, `.num_addresses`).
- **Reachability** = a static graph: subnets are nodes; a `router` host (or
  explicit gateway) that sits in/bridges subnets creates edges. Compute connected
  components from the entry subnet; anything disconnected → `subnet_unreachable`.
- The **tag policy** and **resource caps** come from `Settings` (passed in) — give
  `validate` an optional `policy` argument with sane defaults so it stays pure and
  testable without env. KISS: a small `ValidationPolicy` dataclass
  (`require_digest_pinning: bool = True`, `max_total_cpu: float`,
  `max_total_memory_mb: int`).

### `cli/main.py` — add `validate`
```python
@app.command()
def validate(
    file: Path = typer.Argument(..., exists=True, readable=True),
    strict: bool = typer.Option(False, "--strict", help="Treat warnings as errors."),
) -> None:
    """Validate a scenario file. Exits non-zero if it has errors."""
    # CLI does the file read (spec stays pure), then delegates.
    scenario = load_scenario_file(file)
    diags = validate(scenario, strict=strict)
    typer.echo(format_report(diags))
    raise typer.Exit(code=1 if has_errors(_promote(diags, strict)) else 0)
```
On a `SpecError` from the loader (parse/schema failure), print its message and
exit 1 — don't show a traceback.

### `docs/diagnostics.md`
A table of every code above with: severity, one-line meaning, and the remediation
hint. State that **codes are stable** — renaming one is a breaking change.

## Testing

**Unit (`test_validate.py`)**
- For **each error code**, a tiny fixture spec (or in-code constructed `Scenario`)
  that trips exactly that code — assert the code appears and that a clean spec
  does not trip it. One focused fixture per code keeps failures legible.
- The reference `mini-enterprise.yaml` produces **zero errors** (warnings
  allowed; assert no `severity=="error"`).
- `--strict` promotion: a spec with only warnings → `has_errors` is False
  normally, True under strict.

**Unit (`test_validate_cmd.py`)** — `typer.testing.CliRunner`
- `validate <good file>` → exit 0, report shows no errors.
- `validate <broken file>` → exit 1, the offending code appears in stdout.
- `validate <unparseable file>` → exit 1, a clean message (no traceback).
