## Implementation details

### `common/errors.py`
```python
class RangeError(Exception):
    """Base for all Range errors. Carries a stable `code` and optional `hint`."""
    code: str = "range.error"          # subclasses override
    def __init__(self, message: str, *, hint: str | None = None) -> None:
        super().__init__(message)
        self.message = message
        self.hint = hint
    def __str__(self) -> str:
        return f"[{self.code}] {self.message}" + (f" — {self.hint}" if self.hint else "")
```
Subclasses (each sets `code`): `SpecError("spec.error")`,
`ProvisionError("provision.error")`, `BackendError("backend.error")`,
`TraceError("trace.error")`, `ScoringError("scoring.error")`,
`RunError("run.error")`, `ConfigError("config.error")`. Subclasses may set a more
specific `code` at raise sites by passing it — keep the base simple; do **not**
build a code-registry framework (YAGNI).

### `common/ids.py`
- `new_run_id() -> str` and `new_agent_id() -> str` → ULID strings (sortable by
  creation time). Use `python-ulid`.
- `content_hash(obj: Mapping[str, Any] | str) -> str` → `"sha256:" + hexdigest`
  of canonical JSON (`json.dumps(obj, sort_keys=True, separators=(",", ":"))`)
  or of the raw string. **Invariant: order-independent for dicts** — this is what
  `scenario_id` will rely on.
- `CorrelationIds` (pydantic model, frozen):
  ```python
  class CorrelationIds(BaseModel):
      model_config = ConfigDict(frozen=True)
      run_id: str
      scenario_id: str
      arm_id: str = "control"
      agent_id: str | None = None
      host_id: str | None = None
      step_seq: int = 0
      def as_log_context(self) -> dict[str, str | int]:
          """Non-null fields, for binding into structlog contextvars."""
  ```

### `common/time.py`
- `utc_now() -> datetime` → tz-aware UTC (`datetime.now(timezone.utc)`).
- `HybridTimestamp` (`@dataclass(slots=True, frozen=True, order=True)`):
  fields `wall: datetime`, `step_seq: int`, `source_seq: int`. Ordering must be
  `(step_seq, source_seq)` first so deterministic counters win over wall clock —
  put `wall` last in the comparison, or use explicit `sort_index`. **Document
  why** (wall clocks can skew/collide; the counters are the deterministic order).
- `LogicalClock`:
  ```python
  class LogicalClock:
      """Monotonic per-process clock producing (wall, step_seq, source_seq).

      Seedable for tests via `now_fn`. `tick()` advances the step; `sub()`
      advances within the current step. The (step_seq, source_seq) pair is
      strictly increasing even if `wall` goes backwards.
      """
      def __init__(self, now_fn: Callable[[], datetime] = utc_now) -> None: ...
      def tick(self) -> HybridTimestamp: ...   # step_seq += 1, source_seq = 0
      def sub(self) -> HybridTimestamp: ...     # source_seq += 1, same step
  ```

### `common/logging.py`
- `configure_logging(settings: Settings) -> None` — sets up structlog once:
  processors = [merge contextvars, add log level, timestamper (ISO, UTC),
  **secret-redaction processor**, then `JSONRenderer` if `settings.log_format ==
  "json"` else `ConsoleRenderer`].
- **Secret-redaction processor**: walk the event dict; replace values matching
  known key shapes with `"***REDACTED***"`. Patterns: OpenAI (`sk-...`), AWS
  access keys (`AKIA[0-9A-Z]{16}`), bearer/JWT-ish (`eyJ...` and
  `Bearer\s+\S+`). Keep the regex list small and named; this is a safety net, not
  a vault.
- `get_logger(name: str | None = None) -> structlog.BoundLogger`.
- `bind_correlation(ids: CorrelationIds) -> None` and `clear_correlation() ->
  None` using `structlog.contextvars` so every subsequent log line auto-tags.
- **No `print`.**

### `config/settings.py`
```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_prefix="RANGE_", env_file=os.getenv("RANGE_CONFIG"), extra="ignore",
    )
    profile: Literal["local", "ci", "prod"] = "local"
    log_level: str = "INFO"
    log_format: Literal["console", "json"] = "console"   # default json when prod
    anthropic_api_key: SecretStr | None = None
    openai_api_key: SecretStr | None = None
    postgres_url: str | None = None
    trace_dir: Path = Path("./.range/trace")
```
- A model validator sets `log_format="json"` when `profile=="prod"` unless
  explicitly overridden.
- `get_settings() -> Settings` — module-level cached (`functools.lru_cache`)
  accessor. Load order is defaults → file (`RANGE_CONFIG`) → env (`RANGE_*`), as
  given by pydantic-settings precedence.
- Keys are `SecretStr` so they never render in logs/repr.

## Testing

**Unit**
- *ids*: 1000 `new_run_id()` are unique; sorting them lexicographically matches
  creation order (ULID property, allow for same-ms ties); `content_hash` equal
  for two dicts that differ only in key order; different for different content.
- *errors*: each subclass has its `code`; `str(err)` includes code + hint;
  `isinstance(SpecError(...), RangeError)`.
- *time*: `LogicalClock` sequence is strictly increasing on `(step_seq,
  source_seq)` even when `now_fn` returns a fixed or backwards-going time;
  deterministic given a seeded `now_fn`; `HybridTimestamp` sorts by counters not
  wall.
- *logging*: configure with a capturing processor; assert a log event containing
  `api_key="sk-abc123..."`, an `AKIA...` value, and a bearer token are each
  redacted; assert bound `CorrelationIds` appear on subsequent events; assert a
  `SecretStr` value does not appear in rendered output.
- *settings*: precedence — defaults < a temp `RANGE_CONFIG` file < `RANGE_*` env
  (use `monkeypatch`); `prod` profile flips `log_format` to `json`; `SecretStr`
  repr is masked.

**Property (hypothesis)**
- `content_hash` invariant under dict key permutation (generate a dict, permute
  key order, assert identical hash).
