## Session context

Range turns a **declarative config** into a provisioned, isolated multi-host
range. This step defines that config: the **typed, versioned scenario schema**
humans write and the system parses. It is the spine the whole product hangs off.

The `common` primitives exist (0.2): use `content_hash` for the scenario id,
`SpecError` for failures. **`spec` is a pure package** — no I/O beyond reading the
text/JSON passed to it (the CLI does file reads and hands you the text).

## Goal

A representative YAML loads into typed Pydantic models with a **stable content
hash** (`scenario_id`), and round-trips identically.

## Scope (build this)

- `spec/models.py` — the Pydantic v2 model tree for a scenario.
- `spec/milestones.py` — **minimal** `Milestone` and `Scoring` models (just enough
  to parse; Step 1.3 enriches them in place).
- `spec/loader.py` — `load_scenario(text)` (YAML → models, with helpful error
  locations) + canonicalization → `scenario_id`.
- `spec/schema.py` — JSON Schema export for editor tooling.
- `examples/scenarios/mini-enterprise.yaml` — the reference range (must parse;
  1.3 will refactor it to compose from fragments).

## Out of scope

- **Semantic validation** (referential integrity, CIDR sanity, etc.) → Step 1.2.
- **Milestone/scoring semantics & DAG, fragments & `includes:`** → Step 1.3.
- Provisioning, runtime anything.

Structural, single-object validators (e.g. "exactly one of `content` /
`content_ref`") belong here. Cross-object checks do **not**.

## Deps introduced this step

`ruamel.yaml>=0.18` (round-trip YAML with line numbers). Add to `pyproject.toml`.

## Implementation details

### `spec/models.py`
Pydantic v2 models. **All models set `model_config = ConfigDict(extra="forbid",
frozen=True)`** — `extra="forbid"` catches author typos (critical for a config
language); `frozen=True` keeps specs immutable (good for determinism; 1.3's merge
builds *new* instances).

```python
Role = Literal["entry", "server", "workstation", "router", "target"]

class Metadata(BaseModel):     # name, optional description, labels
    name: str
    description: str | None = None
    labels: dict[str, str] = {}

class Subnet(BaseModel):       # name, cidr (validated as a string here; CIDR math in 1.2)
    name: str
    cidr: str

class Network(BaseModel):
    subnets: list[Subnet]

class Resources(BaseModel):
    cpu: float = 0.5
    memory_mb: int = 512

class Service(BaseModel):
    name: str
    type: str
    port: int
    config: dict[str, Any] = {}

class FileArtifact(BaseModel):
    path: str
    content: str | None = None
    content_ref: str | None = None      # indirection resolved later — never inline real secrets
    mode: str = "0644"
    is_flag: bool = False
    flag_id: str | None = None
    # structural validator: exactly one of content / content_ref;
    # if is_flag then flag_id is required.

class Host(BaseModel):
    name: str
    subnet: str                          # references Subnet.name (checked in 1.2)
    image: str                           # digest-pinned (enforced in 1.2)
    role: Role
    services: list[Service] = []
    files: list[FileArtifact] = []
    env: dict[str, str] = {}
    resources: Resources = Resources()

class Identity(BaseModel):
    username: str
    secret_ref: str                      # indirection — never an inline secret
    locations: list[str] = []            # host names (checked in 1.2)

class Defense(BaseModel):                # minimal in v1.1; expanded in Epic 6
    name: str
    type: str
    config: dict[str, Any] = {}

class Scenario(BaseModel):
    apiVersion: Literal["range/v1alpha1"]
    metadata: Metadata
    network: Network
    hosts: list[Host]
    identities: list[Identity] = []
    defenses: list[Defense] | None = None
    milestones: list[Milestone] = []     # from spec.milestones
    scoring: Scoring = Scoring()         # from spec.milestones
```

### `spec/loader.py`
- `load_scenario(text: str, *, source: str = "<string>") -> Scenario`
  - Parse with `ruamel.yaml` (round-trip mode → line/col available).
  - Construct `Scenario`. On `pydantic.ValidationError`, translate each error to
    a readable message and, where possible, the YAML **line/col** of the
    offending key; raise `SpecError(code="spec.schema", hint=...)`. On a YAML
    parse failure raise `SpecError(code="spec.parse", hint=...)` with the line.
- `load_scenario_file(path: str | Path) -> Scenario` — thin convenience that does
  the **one** file read then delegates to `load_scenario`. Mark clearly that this
  is the only I/O in `spec` and exists for the CLI's use.
- `canonicalize(scenario: Scenario) -> dict` → `scenario.model_dump(mode="json")`
  (deterministic; pydantic preserves declared field order, and `content_hash`
  sorts keys anyway).
- `compute_scenario_id(scenario: Scenario) -> str` → `content_hash(canonicalize(
  scenario))`. **Must be invariant** to YAML key order and comments.

### `spec/schema.py`
- `export_json_schema() -> dict` → `Scenario.model_json_schema()`.
- Optionally write it to `docs/schema/scenario.v1alpha1.json` via a small
  function (don't wire a CLI command yet — that grows in 1.2/8.1; YAGNI).

### `examples/scenarios/mini-enterprise.yaml`
A small but realistic range that **parses** under these models:
- `network`: two subnets, e.g. `dmz` (`10.10.0.0/24`) and `internal`
  (`10.10.1.0/24`).
- `hosts`: a `router`; an `entry` web host in `dmz` with a `Service` (http) and a
  misconfig hint via `env`/`config`; a `server` app host in `internal` holding a
  flag `FileArtifact` (`is_flag: true`, `flag_id: "flag-db-creds"`); a
  `workstation`.
- one `identity` with a `secret_ref` and `locations`.
- a couple of `milestones` referencing the flag (basic; 1.3 reworks into a DAG +
  fragments). Use digest-pinned images (`image: "...@sha256:..."`) so 1.2 is
  happy later.

## Contracts produced

`Scenario` and the whole model tree; `load_scenario`, `load_scenario_file`,
`canonicalize`, `compute_scenario_id`, `export_json_schema`; the minimal
`Milestone`/`Scoring`. These freeze the spec surface other steps build on.

## Testing

**Unit**
- Load `mini-enterprise.yaml` → a `Scenario`; assert key fields (host count,
  roles, the flag).
- **Round-trip identity**: `load_scenario(text)` → `model_dump` → dump to YAML →
  `load_scenario` again → equal models and **equal `scenario_id`**.
- Malformed YAML (`broken_yaml.yaml`) → `SpecError` with `code="spec.parse"` and a
  line number in the hint.
- Unknown field (`broken_extra_field.yaml`) → `SpecError` (`extra="forbid"`).
- `FileArtifact` with both `content` and `content_ref`, and one with neither →
  validation error; `is_flag: true` without `flag_id` → error.
- `export_json_schema()` returns a dict with `$defs`/`properties` (sanity that it
  is JSON-Schema-shaped).

**Property (hypothesis)**
- Build random *valid* `Scenario`s (a small strategy over the models); assert they
  round-trip and that `scenario_id` is invariant under permuting dict key order in
  the serialized form (and under adding/removing YAML comments).
