# Step 4.1 — Trace schema & event model  `[MVP]`

> **Claude Code session prompt.** Self-contained. Read

## Session context

Range's core differentiator is **one timeline**: model + host + network +
lifecycle + score events, all correlated and time-ordered. This step defines the
**schema** for that timeline — a single discriminated-union event model that every
capturer emits and every reader consumes, plus a matching **Parquet schema** and a
stable on-disk layout. It is pure (no I/O); 4.2 writes/reads it, 4.3–4.5 produce
it, 4.6 queries it.

This schema is an **API**: additive evolution only, versioned so the future
ClickHouse/Kafka migration is a backfill, not a break.

## Goal

Every event type round-trips through Parquet **losslessly**, carries the
correlation IDs + ordering key, and is schema-versioned.

## Scope (build this)

- `trace/schema.py`: the event union + per-variant payloads; every event carries
  `CorrelationIds` + `(wall, step_seq, source_seq)` + `source` + `schema_version`.
- `trace/parquet_schema.py`: the explicit pydantic ↔ Arrow/Parquet mapping + the
  on-disk path layout.

## Out of scope

- Writing/reading (4.2); the capturers (4.3–4.5); query/replay (4.6).

## Implementation details

### `trace/schema.py`
A **discriminated union** keyed by a `kind` field (pydantic v2
`Field(discriminator=...)`), grouped by `source`:

```python
SCHEMA_VERSION = 1                       # bump = documented, additive only

class _EventBase(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")
    schema_version: int = SCHEMA_VERSION
    ids: CorrelationIds                  # run/scenario/arm/agent/host/step_seq (0.2)
    wall: datetime                       # UTC
    step_seq: int                        # from the run's LogicalClock
    source_seq: int                      # tiebreak within a step
    source: Literal["model", "host", "network", "lifecycle", "score"]

# model
class ModelEvent(_EventBase):
    source: Literal["model"] = "model"
    kind: Literal["reasoning", "tool_call", "tool_result", "compaction", "token_usage"]
    # payload fields (optional per kind): text, tool_name, tool_args (redacted),
    # result_summary, input_tokens, output_tokens, ...

# host
class HostEvent(_EventBase):
    source: Literal["host"] = "host"
    kind: Literal["process", "auth", "file", "edr_alert"]
    # payload: pid, ppid, exe, argv | user, success | path, op | rule_id, severity

# network
class NetworkEvent(_EventBase):
    source: Literal["network"] = "network"
    kind: Literal["flow", "dns", "http", "pcap_ref"]
    # payload: src_host, dst_host, proto, ports, bytes | query | method,url,status | blob_path

# lifecycle
class LifecycleEvent(_EventBase):
    source: Literal["lifecycle"] = "lifecycle"
    kind: Literal["provision", "ready", "teardown", "snapshot"]

# score
class ScoreEvent(_EventBase):
    source: Literal["score"] = "score"
    kind: Literal["flag", "milestone"]
    # payload: flag_id | milestone_id, credited: bool

Event = Annotated[ModelEvent | HostEvent | NetworkEvent | LifecycleEvent | ScoreEvent,
                  Field(discriminator="source")]
```
- The **ordering key** is `(wall, step_seq, source_seq)` (§8) — provide a helper
  `ordering_key(event) -> tuple` and ensure it yields a **total, stable** order.
- Keep payloads **flat and optional-per-kind** (KISS) rather than deeply nested —
  it maps cleanly to columnar Parquet and stays skimmable. Don't over-model
  variants that no capturer emits yet (YAGNI).
- Events are **append-only and immutable** (`frozen=True`).

### `trace/parquet_schema.py`
- An **explicit** pyarrow schema (one table per `source`, or one wide table with a
  `source` column — choose one; per-source files match the on-disk layout below
  and keep columns dense). Document the choice.
- `events_to_table(events) -> pa.Table` and `table_to_events(table) -> list[Event]`
  with a faithful, lossless mapping (datetimes as `timestamp[us, tz=UTC]`;
  dict/args columns as JSON strings or a map type — pick one, round-trip it).
- **On-disk layout** (stable, partition-friendly):
  `{root}/run_id=<rid>/source=<source>/part-<seq>.parquet`
  where `{root}` is the block-volume path (default) or the object-storage bucket
  (4.2). Provide `partition_path(root, run_id, source, part_seq) -> str`.
- `schema_version` is a column on every row.

### ADR 0007
Record: the discriminated-union design; the per-source-vs-wide-table choice; the
versioning rule (additive only; bump procedure); why this makes ClickHouse/Kafka a
backfill (append-only + versioned schema).

## Infrastructure (Terraform)

  storage-infra decision (block volume vs object storage). No OCI resource here.

## Contracts produced

## Testing

**Unit (pure — runs in CI):**
- Each event variant constructs, validates (`extra="forbid"`), and exposes the
  ordering key; the discriminator selects the right type on parse.
- `ordering_key` yields a **total, stable** order on a mixed event list (sorting is
  deterministic across runs).
- `schema_version` present on every event/row.

**Property (hypothesis):**
- For each event type, `events_to_table` → `table_to_events` is **lossless**
  (generate random valid events, round-trip, assert equality). Cover datetime tz,
  args/dict columns, and optional-field presence/absence.
