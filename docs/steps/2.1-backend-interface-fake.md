## Session context

The spec layer is done (Epic 1): a `Scenario` parses, validates, and scores.
Now we define **how a scenario becomes a running range** — but *backend-agnostic*.
This step writes the `Backend` Protocol + a `LifecycleSM` + a registry, plus a
**fake, in-memory backend** that implements the whole contract deterministically.
The fake backend is what lets the entire downstream pipeline (orchestrator,
agents, scoring, trace) be tested **with zero Docker** — so it must be faithful to
the contract, not a toy.

## Goal

Downstream code can target `Backend`, and a full (fake) provision → exec →
snapshot → restore → teardown cycle works in tests with no infrastructure.

## Scope (build this)

- `provision/base.py` — the `Backend` Protocol, the data types (`RangeHandle`,
  `ExecResult`, `SnapshotId`), the `LifecycleSM`, and the backend `registry`.
- `provision/fake.py` — an in-memory backend modeling hosts/networks/files as
  Python objects, with a tiny deterministic command interpreter.

## Out of scope

- Docker (2.2), real networking (2.3), gVisor (2.4), images (2.5), real snapshots

## Implementation details

### `provision/base.py`
```python
class ExecResult(BaseModel):           # serialized into the trace
    stdout: str
    stderr: str
    exit_code: int
    duration_s: float

SnapshotId = NewType("SnapshotId", str)

@dataclass(slots=True)
class RangeHandle:
    """Opaque, per-backend handle to a provisioned range."""
    run_id: str
    scenario_id: str
    hosts: dict[str, "HostHandle"]     # host_id -> resolved host (ip, backend ref)
    network: "NetworkInfo"             # subnet map, host IPs (filled by 2.3)
    backend: str                       # backend name (for re-resolution)

class Backend(Protocol):
    """Backend-agnostic provisioner contract. Every method takes/propagates
    CorrelationIds and emits lifecycle events to the injected trace sink."""
    async def provision(self, scenario: Scenario, run_ctx: RunContext) -> RangeHandle: ...
    async def exec(self, handle: RangeHandle, host_id: str, argv: Sequence[str],
                   *, timeout_s: float = 30, user: str | None = None) -> ExecResult: ...
    async def copy_in(self, handle: RangeHandle, host_id: str, src: bytes, dest: str,
                      *, mode: str = "0644") -> None: ...
    async def copy_out(self, handle: RangeHandle, host_id: str, src: str) -> bytes: ...
    async def snapshot(self, handle: RangeHandle) -> SnapshotId: ...
    async def restore(self, handle: RangeHandle, snap: SnapshotId) -> None: ...
    async def teardown(self, handle: RangeHandle) -> None: ...   # idempotent
```
- `RunContext` (small dataclass): `CorrelationIds` + the injected **trace sink**
  (a `Protocol` with `emit(event)`) + the seeded `Random`. Keep it minimal; this
  is how every backend op stays correlated and deterministic.
- **`LifecycleSM`**: states `CREATED → PROVISIONING → READY → RUNNING →
  SNAPSHOTTED → TEARDOWN → DESTROYED`; a transition table; illegal transitions
  raise `ProvisionError(code="provision.illegal_transition")`. Small and explicit
  — a dict of allowed edges, not a framework.
- **`registry`**: `register_backend(name, factory)` + `get_backend(name,
  **kwargs) -> Backend`. This is the DI seam (D8). Backends self-register on
  import.

### `provision/fake.py`
- `FakeBackend` implements `Backend` over plain dicts: hosts, per-host virtual
  filesystem, network map. Fully **deterministic** (seeded; no wall-clock-dependent
  behavior).
- `exec` runs a **tiny built-in interpreter** — enough to satisfy
  agent/scorer/trace tests, not a shell: `ls`, `cat <path>`, `whoami`, a fake
  `nmap <subnet>` (returns the seeded host map), and **flag reads** (`cat` of a
  planted flag path returns the deterministic flag value). Unknown commands return
  a non-zero `ExecResult`, never raise.
- Emits the same lifecycle + exec events to the trace sink that a real backend
  would, so trace-layer tests (Epic 4) can run on the fake.
- `teardown` is idempotent; `snapshot`/`restore` copy/restore the in-memory state.

> Keep the interpreter intentionally minimal (YAGNI) but **contract-complete**:
> if the orchestrator/scorer need a behavior, the fake must model it, because the
> fake is the CI substrate for everything above the provisioner.

## Testing

**Unit (core — ≥90% coverage on `provision/base` + `fake`)**
- *lifecycle*: every legal transition allowed; a representative set of illegal
  transitions raise `provision.illegal_transition`.
- *fake backend*: `provision` a 2-host scenario → `READY`; `exec whoami`,
  `cat` a planted flag (deterministic value), fake `nmap` lists the host map;
  `copy_in`/`copy_out` round-trip; `snapshot` → mutate → `restore` → state
  matches; **`teardown` is idempotent** (calling twice is a no-op, no raise).
- *determinism*: same scenario + seed ⇒ identical flag values, identical host map,
  identical exec outputs.
- *concurrency*: concurrent `exec` calls on different hosts don't corrupt state
  (run several under `asyncio.gather`).

**Shared contract fixtures (`conftest.py`)**
- Provide a parametrizable "backend contract" test helper that asserts the
  `Backend` behavioral contract (provision→exec→teardown, idempotent teardown).
  2.2 will reuse it against the Docker backend, so write it backend-neutral now.
